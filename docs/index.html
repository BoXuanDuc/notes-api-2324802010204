2. Phân tích 5 đặc tính điện toán đám mây NIST

  1. Tự phục vụ theo yêu cầu (On-demand self-service): Sinh viên có thể tự tạo Codespace bằng cách nhấn Create codespace mà không cần yêu cầu quản trị viên cấp phát máy tính.
  2. Truy cập mạng rộng (Broad network access): API có thể được truy cập thông qua Internet bằng URL Codespaces từ máy tính và điện thoại.
  3. Gộp tài nguyên (Resource pooling): GitHub sử dụng hạ tầng máy chủ và tài nguyên tính toán chung để cung cấp môi trường cho nhiều người dùng.
  4. Co giãn nhanh (Rapid elasticity): Người dùng có thể tạo, dừng và khởi động lại Codespace khi cần thiết, thay vì phải tự mua thêm máy tính.
  5. Dịch vụ đo lường được (Measured service): GitHub theo dõi mức sử dụng Codespaces thông qua core-hours và dung lượng lưu trữ trong Billing Usage.

3. Kết quả thực hành

Đã xây dựng thành công API Hello Cloud sử dụng Node.js và Express trên GitHub Codespaces.

API trả về thông tin máy chủ gồm hostname, hệ điều hành, CPU, RAM và thời gian hoạt động.
